# 🐱 粉猫捉虫 · C 语言零基础互动学堂

> 一边读讲解、一边在网页里写 C 代码、点一下就能运行；还有一只粉色像素小猫「捉虫」陪着你——你写代码，它就有小鱼干吃。

## ✨ 这是什么

一个**面向完全零基础学习者**的 C 语言教学网站，纯静态、零依赖、可直接部署到任何静态托管服务。

- **从概念讲起**：什么是程序、什么是编译、`main` 函数为什么必须有，一步一步来，不跳步。

- **在浏览器里真跑代码**：内置一个用 JavaScript 从零实现的迷你 C 解释器，点「运行」立刻看到输出。

- **中文报错，会指人行**：报错会告诉你「第几行、错在哪、怎么改」，还会识别中文标点、漏分号、忘了 `&` 这些新手高频错误。

- **养成小游戏**：完成 57 个练习任务和 12 个「捉虫」关卡可赚小鱼干，用来喂猫、买玩具和装扮。猫猫有饱食度、心情、亲密度和等级，会随着真实时间慢慢变饿。

- **捉虫模式**：专门训练找 bug 的能力——每关给一段有问题的代码，你要把它修好。

- **进度自动保存**：代码和进度都存在浏览器 `localStorage` 里，关掉网页下次回来还在。

- **像素小猫是代码画的**：不是图片素材，而是用代码逐像素画出来的，因此完全离线可用。


## 🚀 快速开始

三种方式，任选其一：

**1. 直接打开**（最简单）：双击 `index.html`，用浏览器打开就能用。

**2. 本地服务器**（推荐，体验最完整）：

```bash
node tools/dev-server.mjs      # 默认 http://localhost:5173
# 或者用任何静态服务器，例如：
python -m http.server 5173
```

**3. 部署到网上**：本站是纯静态站点，把整个文件夹上传即可。GitHub Pages / Gitee Pages / Vercel / Netlify 都行，详见 [docs/publish.md](docs/publish.md)。仓库里已经带好 GitHub Pages 的自动发布配置（`.github/workflows/deploy-pages.yml`）。

## 🧠 迷你 C 解释器能力范围

| 支持 | 不支持（会给出友好提示） |
| --- | --- |
| `int` / `long` / `short` / `char` / `float` / `double` / `void` | `struct`、`union`、`enum`、`typedef` |
| `if` / `else` / `switch` / `while` / `do-while` / `for` / `break` / `continue` | `goto`、函数指针、可变参数 |
| 一维 / 二维数组，`char` 字符串 | 文件读写、`malloc` 等动态内存 |
| 函数、递归、指针（`&`、`*`、指针运算、指针作参数） | 多文件工程、预处理器的高级用法 |
| `printf` `scanf` `puts` `putchar` `getchar` `strlen` `strcpy` `strcat` `strcmp` `abs` `fabs` `sqrt` `pow` `floor` `ceil` `round` `fmod` `rand` `srand` `time` `atoi` `toupper` `tolower` | 完整 C 标准库 |

> 它是**教学用的子集解释器**：为了让报错信息对孩子友好，它会在数组越界、空指针解引用、死循环等真实 C 语言里「行为不确定」的地方主动报错。学会本站内容后，请换用真正的编译器（gcc / Dev-C++ / VS Code + MinGW）继续进阶。

## 🛠 开发与自检

不需要安装任何依赖（Node 18+ 即可）：

```bash
npm test          # 跑全部自检：解释器测试 + 课程内容校验
npm run serve     # 起本地服务器
npm run art       # 把像素猫画稿渲染成 PNG，改画稿时可以肉眼看效果
npm run e2e       # 端到端自检：用真实浏览器模拟「做题 → 判题 → 拿奖励 → 喂猫」
```

`npm test` 会验证两件最重要的事：

1. 解释器行为正确（输出、报错文案、边界情况）；

2. **每一道题的参考答案都能真的通过它自己的判题**（防止题目和答案对不上）。


## ❓ 常见问题

**代码保存在哪里？会不会丢？**

存在你浏览器的 `localStorage` 里，换浏览器或清理浏览器数据就会丢。想要长期保存，可以把代码复制到自己的文件里。

**为什么我的程序能跑，但在真正的编译器里报错？**

迷你解释器为了教学放宽了一些规则（比如自动帮你补上 `#include <stdio.h>`，并在报错信息里给出中文提示）。它会在需要时提醒你「真正的 C 语言里应该怎么写」。

**小猫会不会饿死？**

不会。饱食度和心情最低降到 0，猫猫只会「更想你一点」，不会生病、不会离开。

**可以离线用吗？**

可以。整个站点没有任何外部请求（没有 CDN、没有字体、没有图片素材），直接双击 `index.html` 就能用。
